# persona

複数のペルソナがサービスを使う過程を検証し、操作の証拠、利用者視点の仮説、改善の優先度を残す AI スキルです。

目的・知識・操作条件・離脱条件を変えたタスク検証を行います。実ユーザー調査を再現できたとみなさず、早い段階での問題発見と、人に確認する問いの具体化に使います。

## 使う

このリポジトリを Codex のプロジェクトとして開くと、[service-persona-review](.agents/skills/service-persona-review/SKILL.md) を利用できます。別のプロジェクトでは、このフォルダをそのプロジェクトの `.agents/skills/` にコピーしてください。ブラウザ操作ツールは実行環境側で用意します。特定のサービスやモデルへの依存はありません。

配置は [OpenAI のスキル仕様](https://learn.chatgpt.com/docs/build-skills) に従っています。追加後に表示されなければ Codex を再起動してください。

```text
$service-persona-review
https://example.com を、想定利用者に合う6種類のペルソナで検証してください。
まず価値を理解し、主要な機能を使い、失敗から戻れるかまで確認してください。
実際の観察と推測を分け、改善の優先度と、人に確かめる質問をまとめてください。
```

分かっている条件だけを足せます。

```text
対象：テスト環境の予約サービス
想定利用者：初めて予約する人と、毎週利用する人
大事なタスク：予約条件の比較、予約、日時の変更
利用環境：スマートフォン中心
許可：用意したテストアカウントで架空の予約を作成・変更してよい
対象外：本番予約、決済、他人への通知
成果物：日本語のレポートと JSON
```

画面や仕様しかない場合は「資料レビュー」と指定します。URL・画面・仕様のいずれもなければ、まず対象を確認します。

## 標準の検証

1. サービスの目的と、検証できる範囲を整理する。
2. ペルソナの目的・知識・制約を固定し、重要なタスクを割り当てる。
3. ペルソナごとに試し、画面・操作・結果の証拠を記録する。
4. 7観点で評価し、事実と仮説を分けて統合する。
5. 優先する改善、維持したい良さ、実ユーザーへ確かめる問いを出す。

標準は4〜6ペルソナ、重要タスク3〜5件、合計8〜12セッション程度です。これは作業量の初期値で、必要人数や統計的な標本数ではありません。利用者が限定されるサービスでは、無関係なペルソナを減らします。

| ペルソナの種 | 行動を変える条件 |
| --- | --- |
| はじめての利用者 | 専門用語を知らず、導線と説明を頼る |
| 時間に余裕がない利用者 | 最小の手間で目的に到達したい |
| 比較して判断する利用者 | 価格・制約・代替手段を確認したい |
| 慎重に判断する利用者 | 情報提供、公開範囲、取り消し方法を確かめる |
| 習熟した継続利用者 | 反復作業や既存のやり方との違いを確かめる |
| 操作条件に制約がある利用者 | キーボードのみ、拡大表示など具体的な条件で使う |

年齢や性別から行動を決めません。インタビューや問い合わせがあれば、その根拠を優先して調整します。

## 得られるもの

- ペルソナ × タスクの結果表。未実行・途中停止・環境の制約も表示。
- 7観点の根拠付き評価。未確認は低得点にせず `null` とする。
- 再現手順、証拠、影響、改善案、再検証条件を備えた指摘。
- ペルソナ間の意見の違いと、残すべき長所。
- 実ユーザーへの確認項目と、改善前後を比較するための記録。

評価軸は **価値の伝達、見つけやすさ、理解しやすさ、操作効率、失敗からの復帰、信頼と判断材料、利用条件への対応** です。総合点や架空の満足度を作るより、どの条件で何が起きたかを重視します。

出力形式は [レポートの型](.agents/skills/service-persona-review/assets/report-template.md) と [構造化データの仕様](.agents/skills/service-persona-review/references/output-contract.md) を参照してください。[最小の出力例](.agents/skills/service-persona-review/assets/example-review.json) は架空の資料を使った例で、実サービスの検証結果ではありません。

## 検証

スキル自体に Python パッケージの追加は不要です。JSON の整合性検査には Python 3.9 以降を使います。

```bash
python3 .agents/skills/service-persona-review/scripts/validate_review.py review.json
python3 -m unittest discover -s tests -v
```

検査は必須項目、証拠参照、未実行を成功扱いしないこと、採点条件などを確認します。証拠の真実性や人間の行動の再現性を保証するものではありません。
